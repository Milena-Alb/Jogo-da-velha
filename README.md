# Jogo-da-velha# Jogo da Velha 🎮✨

Um jogo da velha interativo desenvolvido em Python com a biblioteca Pygame. O projeto apresenta uma interface intuitiva e oferece dois modos de jogo: 🎲

- **Jogador vs Jogador**
- **Jogador vs Computador**

## Tecnologias Utilizadas 🛠️

- Python 3.12
- Pygame 2.6.0

## Estrutura do Projeto 📂

```
Jogo-da-velha/
├── Assets/
│   └── Ubuntu-Medium.ttf  # Fonte utilizada no jogo
├── index.py                # Arquivo principal do jogo
└── README.md              # Documentação do projeto
```

## Como Executar o Projeto 🚀

1. Certifique-se de ter o Python 3.12 e o Pygame instalados.
2. Clone este repositório:

   ```bash
   git clone https://github.com/seu-usuario/jogo-da-velha.git
   ```

3. Navegue até o diretório do projeto:

   ```bash
   cd jogo-da-velha
   ```

4. Execute o jogo:

   ```bash
   python index.py
   ```

## Funcionalidades 🌟

- Interface gráfica simples e atrativa.
- Verificação automática de vitórias e empates.
- Reinício rápido para novas partidas.

## Fontes e Estilo 🎨

Para o design do jogo, foi utilizada a fonte **Ubuntu**, que foi baixada do [Google Fonts](https://fonts.google.com/) e incluída na pasta `Assets`. Isso garante que a experiência visual seja consistente em qualquer sistema.
